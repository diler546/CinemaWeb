# КАДР — учебный сервис бронирования билетов в кинотеатр

Тёмный минималистичный учебный сервис бронирования билетов в кинотеатр. Один экран: вы выбираете фильм, удобный сеанс и места на интерактивной схеме зала. Сумма пересчитывается мгновенно, билет оформляется и попадает в «Мои билеты». Всё работает без серверов и баз данных.

## Возможности

- **Афиша:** 4 фильма в прокате, у каждого — 2 сеанса (всего 8 сеансов в двух залах: «Зал 1», «Зал 2»).
- **Схема зала:** интерактивная отрисовка зала 4 ряда × 6 мест с экраном внизу и легендой состояния мест.
- **Состояния мест:** свободно (голубой), выбрано (янтарный), занято (красный, недоступно).
- **Выбор мест:** множественный выбор нескольких мест, повторный клик снимает выбор; занятые места заблокированы.
- **Расчёт суммы:** итоговая стоимость одной брони = число мест × 450 ₽.
- **Оформление:** создание учебной брони с генерацией короткого кода заказа (`KD-XXXX`).
- **«Мои билеты»:** список оформленных билетов (фильм, дата, сеанс, места, сумма) с мгновенной отменой.
- **Отмена:** после отмены места на схеме соответствующего сеанса снова становятся свободными.
- **Сброс:** «Сбросить все брони» с подтверждением через `dialog`.

## Технологии

- **HTML5** — семантическая разметка, ARIA-атрибуты, навигация клавиатуры.
- **CSS3** — кастомные свойства (custom properties), Grid/Flexbox, тёмная тема, адаптивные media-переключения.
- **Vanilla JavaScript** — ES modules (ES2020+), без фреймворков и сборщиков.

Всё приложение — один статический HTML-файл, не требует сборки и внешних зависимостей.

## Как запустить

Приложение — статический сайт, поэтому достаточно локального HTTP-сервера.

1. Откройте папку проекта в редакторе (VS Code).
2. Установите расширение **Live Server** (если ещё не установлено).
3. Правой кнопкой по `index.html` → **Open with Live Server**.
4. Страница откроется по адресу вида `http://127.0.0.1:5500`.

> Модули (`main.js`, `data.js`, `storage.js`) используют ES-модули и требуют защищённый протокол HTTP, поэтому открывать файл `index.html` двойным щелчком локально нельзя.

## Как это работает

1. **Данные:** `data.js` содержит список вымышленных фильмов и сеансов, цену билета и конфигурацию зала. Исходная занятость каждого сеанса генерируется детерминированным псевдослучайным алгоритмом (хеш + PRNG) по ключу `filmId:sessionId`, поэтому после перезагрузки она стабильна.
2. **Состояние:** `main.js` хранит текущий фильм/сеанс, выбранные места (`Set`) и брони пользователя.
3. **Брони:** `storage.js` сохраняет массив брони в единственный ключ `kadr-cinema-bookings-v1` и перехватывает ошибки (приватный режим, квота, повреждённый JSON, неверный формат).
4. **Поток:** выбор фильма → сеанс → мест → «Забронировать» → бронь появляется в «Моих билетах» → отмена освобождает места.

## Проверка качества

Создан и проверен в браузере:

- основной сценарий бронирования и отмены;
- перезагрузка страницы (персистентность бронирований);
- сброс всех броний с подтверждением;
- повреждённый JSON и некорректная структура данных;
- ширины вёрстки 360 / 768 / 1280 px;
- Lighthouse: Accessibility — 100.

## Ограничения

Учебное демо:

- реальная бронь, оплата и серверная часть не используются;
- данные хранятся только в текущем браузере (`localStorage`) и могут быть потеряны после его очистки;
- занятость мест «прошлого сеанса» — искусственная, генерируется алгоритмом.

## Создание проекта

Сайт создан с помощью ИИ-ассистента, затем проверен в браузере и доведён до рабочего состояния.

Примеры промптов, использованных при разработке:

1. «Сделай адаптивную схему зала 4 × 6 на кнопках: свободные — голубые, занятые — красные и disabled, выбранные — янтарные, с экраном снизу и aria-label вида "Ряд 2, Место 4, Свободно"».
2. «Реализуй в ванильном JS выбор нескольких мест, пересчёт суммы и создание одной брони; сохраняй массив броней в один ключ localStorage и восстанавливай занятость после перезагрузки».
3. «Добавь отмену билета с мгновенным освобождением мест на схеме нужного сеанса, подтверждение сброса всех бронирований и обработку повреждённого JSON без падения страницы».
